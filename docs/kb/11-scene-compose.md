# Scene Compose (Multi-Image Edit)

## Overview

Combine up to 5 images into a single scene using AI. Unlike Place Products (manual positioning), Scene Compose uses AI to intelligently merge images based on your description.

## How to use

1. Select 1-5 images
2. Write a scene description (e.g., "arrange these products on a marble table with warm lighting")
3. Optionally choose an aspect ratio
4. Click Generate

## Credits

2 image credits per composition.

## When to use Scene Compose vs Place Products

| Feature | Scene Compose | Place Products |
|---------|--------------|----------------|
| Control | AI decides positioning | You control positioning manually |
| Images | 1-5 source images | Unlimited cutouts |
| Result | AI-generated scene | Manual composite + AI Blend |
| Best for | Quick creative compositions | Precise product placements |
| Credits | 2 credits | Free + 1 for AI Blend |

## Tips

- Be specific in your description about how you want the images arranged
- Include lighting and mood descriptions
- Works great for creating product flat-lays
- Maximum 5 images per request
