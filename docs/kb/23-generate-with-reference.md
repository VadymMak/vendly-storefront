# Generate with Reference (Image Variations)

## Overview

Create variations of an existing image. Upload a reference image and describe what you want — the AI generates a new image inspired by your reference while incorporating your text prompt.

## How to use

1. Upload a reference image
2. Write a description of what you want to change or achieve
3. Adjust strength (how much the reference influences the result)
4. Choose aspect ratio
5. Click Generate

## Strength Parameter

- **Low (0.1-0.3):** Heavy reference influence — result closely matches the original
- **Medium (0.5, default 0.75):** Balanced — keeps the overall composition but with creative freedom
- **High (0.8-1.0):** Minimal reference influence — more creative, less tied to original

## Use Cases

- Create color variations of a product photo
- Generate similar images in different styles
- Create a series of related images with consistent theme
- Get inspired by a photo and create something similar
