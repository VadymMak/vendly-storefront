# Own API Keys (BYOK)

## Can I use my own AI provider API keys?

No. VendShop AI Studio does not offer "Bring Your Own Key" (own API keys from Replicate, xAI, fal.ai, BFL, OpenAI or others) to customers. Everything runs on VendShop's own AI accounts — there is nothing to set up, and there is no separate BYOK plan.

## What do I use instead?

- Every plan (Free, Starter, Pro) includes monthly image and video credits.
- Need more? Buy a credit pack — pack credits never expire.
- See "Plans & Pricing" and "Credits System" for the numbers.

## I saved API keys before — what happens to them?

They stay encrypted and are no longer used for your generations. Generations use credits as on every plan.
