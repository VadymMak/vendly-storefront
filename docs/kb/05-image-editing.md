# Image Editing (AI Edit / Improve)

## Overview

Edit and enhance images using AI. Describe what changes you want and AI applies them while keeping the original composition.

## How to use

1. Upload or select an image in Studio
2. Click "Improve Photo" in Quick Tools, or open the AI Edit panel
3. Write an instruction describing the change (e.g., "make the lighting warmer", "add a blurred background")
4. Click Generate

## Technical Details

- Input images are automatically resized to max 1024px before processing
- Original aspect ratio is preserved
- Output format matches input format
