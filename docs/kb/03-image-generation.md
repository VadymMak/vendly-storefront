# Image Generation (Text-to-Image)

## Overview

Generate professional images from text descriptions. Describe what you want and AI creates a unique image in seconds.

## How to use

1. Go to Studio → Generate Image
2. Write a description of what you want (the more specific, the better)
3. Choose a style preset (Product, Food, Social, Beauty, Interior, or Custom)
4. Select a size preset
5. Choose quality tier
6. Click Generate

## Quality Tiers

| Tier | Label | Credits | Speed | Best for |
|------|-------|---------|-------|----------|
| Fast | Quick | 1 credit | ~3 seconds | Quick drafts, iteration |
| Quality | Best | 2 credits | ~8 seconds | Final content, social media |
| Premium | HD | 3 credits | ~15 seconds | Print, high-resolution needs |

**Note:** Free plan users can only use Quick tier unless they have purchased bonus credits.

## Style Presets

Style presets add professional context to your prompt automatically:

- **Product photo** — Clean product photography style
- **Food** — Warm lighting, appetizing composition
- **Social post** — Optimized for social media
- **Beauty** — Soft, professional beauty photography
- **Interior** — Architectural and interior design style
- **Custom** — No style modification, uses your prompt as-is

## Size Presets

| Preset | Aspect Ratio | Resolution | Best for |
|--------|-------------|------------|----------|
| Instagram | 4:5 | 1080×1350 | Instagram feed posts |
| Square | 1:1 | 1080×1080 | Profile pictures, thumbnails |
| Story/Reel/TikTok | 9:16 | 1080×1920 | Stories, Reels, TikTok |
| Landscape/Website | 16:9 | 1920×1080 | Website banners, covers |
| Product/E-commerce | 1:1 | 800×800 | Online store listings |

## Output Formats

- **WebP** (default) — Smallest file size, best for web
- **PNG** — Lossless, supports transparency
- **JPEG** — Universal compatibility

## Tips for Better Results

1. **Be specific**: "A professional photo of a freshly baked croissant on a marble counter with morning light" is better than "bread photo"
2. **Mention lighting**: "warm lighting", "studio lighting", "natural daylight"
3. **Mention style**: "minimalist", "editorial", "cinematic"
4. **Mention camera angle**: "overhead shot", "45-degree angle", "close-up"
5. **Use style presets**: They add professional photography terms automatically

## AI Models Used

The system automatically selects the best AI model for your chosen quality tier:

- **Quick tier**: Flux Schnell — fastest generation
- **Best tier**: FLUX.2 Dev or Grok Imagine — balanced quality/speed
- **HD tier**: FLUX.2 Pro — highest quality

If one model is unavailable, the system automatically falls back to the next available model.

## Grok Imagine (Free Model)

Grok Imagine by xAI is available as a free model in the Best quality tier. It costs 0 credits and produces good quality results. The system may use it automatically as a fallback.
